Keyboard Controls

W / S — Throttle up / down

↑ / ↓ — Pitch down / up (nose down / pull up)

← / → — Roll left / right

A / D — Yaw left / right (rudder)

Shift — Boost (limited fuel, regenerates)

F — Fire flares

C — Toggle camera view

R — Reset plane (if crashed)

SPD: 0 kts
ALT: 0 ft
THR / BST
RINGS: 0 / 0
